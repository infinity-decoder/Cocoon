# Architecture Decision Records (ADRs)

## ADR-001: Integer-Scaled Monetary Representation for Multi-Decimal Currencies

### Status
Accepted

### Context
Cocoon is evolving from a personal Pakistani Rupee (`₨`) expense tracker to an international personal and business management application. Business users operate in markets requiring:
1. Standard 2-decimal fiat currencies (PKR, USD, EUR, INR, GBP).
2. 3-decimal currencies (KWD, BHD, OMR, JOD, TND).
3. 0-decimal currencies (JPY, KRW).
4. Sub-unit precision for wholesale quantity discounting and fractional taxation.
Using standard IEEE-754 JavaScript floating-point numbers (`number`) introduces binary floating-point drift (e.g. `0.1 + 0.2 = 0.30000000000000004`), which causes ledger unbalance over time.

### Decision
Represent all durable monetary amounts as `bigint` scaled by `10^4` (`10000n`).
* 1.00 USD = `10000n`
* 1.250 KWD = `12500n`
* 100 JPY = `1000000n`
All additions, subtractions, multiplications, and ledger balance queries execute via the domain `Money` class. Formatting to user-visible strings occurs strictly at the presentation boundary.

### Consequences
* **Positive:** Completely prevents floating-point penny drift; supports 0, 2, and 3-decimal currencies in a single uniform column type (`INTEGER` in SQLite).
* **Tradeoff:** Display code must explicitly invoke `money.format()` or `money.toDecimal()`.

## ADR-002: Dual Hardware and Camera Barcode Scanning Architecture

### Status
Accepted

### Context
Retail shops and distributors use physical handheld USB or Bluetooth barcode scanners at checkout counters. These scanners operate as HID (Human Interface Device) keyboards, emitting rapid bursts of keystrokes followed by an `Enter` key. Simultaneously, mobile users scanning inventory stock on the move require camera-based barcode scanning.

### Decision
Implement `HardwareBarcodeScannerService` as a singleton listening to window keystrokes with burst detection:
* Keystroke intervals under 50ms are captured into a barcode buffer.
* An `Enter` key with length >= 3 flushes the buffer to registered subscribers and suppresses default form submission.
* Normal user typing into input fields is preserved unless tagged with `data-barcode-receiver`.
* Camera scanning (via Capacitor barcode plugin) and hardware wedge scanning emit identical `BarcodeScanResult` events to application services.

### Consequences
* **Positive:** Retail shop owners can plug in any standard USB or Bluetooth barcode scanner without specialized Android driver setup.

## ADR-003: Unified Encrypted Database Backup with Local Attachment Bundle

### Status
Accepted

### Context
Users attach receipts, invoices, and bill images. Storing multi-megabyte base64 strings inside JSON or direct SQLite tables causes database file bloat. However, backing up only JSON leaves attachments stranded on the old device upon restore.

### Decision
1. **At Rest:** Store photos in Android app-private storage (`context.getFilesDir() + "/attachments/"`) and store relative file paths in the database.
2. **At Backup Time:** Package the SQLite database snapshot and the attachments directory into a single encrypted ZIP / TAR archive (`.cocoonenc` or `.cocoonbackup`), signed with an HMAC-SHA256 checksum.
3. **At Restore Time:** Validate checksum, stage the database, verify referential integrity, and extract attachments atomically before committing the restore.

### Consequences
* **Positive:** Keeps native SQLite database lean and performant while guaranteeing 100% complete data recovery on new devices.
